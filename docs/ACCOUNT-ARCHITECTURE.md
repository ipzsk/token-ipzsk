# IPZSK 账户与计费架构

实施日期：2026-09-07。用户入口 www.ipzsk.com/account，网关与管理台 api.ipzsk.com。

## 账户关系

已验证邮箱 → 固定 users.id → 多个独立 ipz_ API 凭证 → 共用账户钱包 → 号池 APIMart Key。

网站使用邮箱 + 密码登录。注册时设置至少 12 位密码并验证邮箱；验证完成后返回登录页，不自动登录。忘记密码通过邮箱验证码重置，并注销旧会话。业务账户在邮箱验证成功后创建。若存在唯一一条邮箱相同、尚未绑定登录的后台账户，则在验证成功后绑定原账户，保留原凭证、钱包和历史记录。邮箱重复的后台账户要求人工核对，不自动选择。用户禁用仍阻止登录和调用。

每个用户最多 20 把有效凭证。凭证有名称、可选有效期、每分钟请求上限、最后使用时间和吊销时间。只在创建时返回明文，数据库保留哈希和前缀。新增凭证不会吊销其他凭证。所有账户共用平台上游池；用户响应不公开上游身份和成本。

每个新请求同时保存 user_id、access_token_id、上游 key_id。旧请求的 access_token_id 保留空值，避免伪造历史归属。

## 钱包

采用 PostgreSQL 事务与 users 行锁串行化同一账户的充值、冻结和结算。使用 8 位小数，计算使用 BigInt。

- wallet_entries：保留原充值流水，金额为正，兑换码唯一，重复兑换不重复入账。
- wallet_debits：消费流水，request_id 唯一，不修改已结算记录。
- request_billing：请求冻结、待核对、已结算、已释放状态及售价快照。
- 账面余额 = 累计充值 − 已结算消费。
- 冻结金额 = reserved 和 pending 请求的冻结金额合计。
- 可用余额 = 账面余额 − 冻结金额。

按请求创建日（北京时间）统计每日 token 和用户扣款。延后核对的扣款会更新原请求日的统计；钱包流水显示实际结算时间。

## 收费开关与价格

默认关闭收费。关闭期间继续原有调用和成本记录，不追扣历史请求。超级管理员可在“账户与账单 → 计费与核对”确认倍数后开启。

用户费用 = 请求使用的 APIMart 文字定价算法 × 售价倍数；Credits 按当前账户约定 1:1 记人民币元。与上游实际扣费 cost_cny、上游成本估算 estimated_cost_cny 分开保存。价格版本、模型费率和倍数随请求冻结；后续修改不影响进行中的请求。

开启时支持已定价的文字接口，必须提供 max_tokens、max_completion_tokens 或 max_output_tokens。未定价接口、媒体接口、搜索工具和特别服务档位拒绝调用，避免无规则收费。

冻结预算采用请求 JSON 的 UTF-8 字节数 × 2 + 4096 作为输入预算，加指定的最大输出 token，并使用该模型所有阶梯和缓存类别中的最高费率。这是保守预算，不保证等于实际 tokenizer 计数。若结算费用超过冻结预算，不超扣钱包，进入待核对。正式收费前应结合真实应用评估冻结预算对长上下文和工具调用的影响。

请求成功且用量可计价时结算，释放多余冻结款。缓存明细缺失时沿用定价文档的零缓存假设；明确非零但缺失缓存费率时不自动计费。reasoning token 已包含在输出时不重复计入。

确定未发送上游时释放冻结。超时、断流、上游错误或缺少用量时保留冻结，进入 pending；24 小时为人工核对期限，面板标明逾期，不凭时间自动认定免费。核对金额必须在冻结预算内；填写 0 释放冻结，说明至少 5 字。重复核对不重复扣款。

进程重启将未完成请求和冻结转为待核对，不自动重放上游请求。

## 管理员

独立用户名与密码，密码至少 16 位。超级管理员管理收费、人员、导出和手工核对；运营可管理用户、号池和充值码但不能导出充值码或修改收费；只读只能查看。管理员会话与用户邮箱会话分开。停用管理员立即注销其会话；修改密码会注销该管理员所有会话。原 admin 账户保留原密码。

管理 API 的写操作记录操作人、路由、状态和时间。已有业务审计继续保留。历史缺失的操作人标为系统/历史记录，不推断归属。

## 页面与接口

管理台新增“账户与账单”：每日用量、平台凭证、钱包流水、计费与核对、管理员、修改密码、操作审计。

用户 /api/me/tokens 提供查看和新建，POST /api/me/tokens/:id/revoke 吊销；这些凭证管理操作要求邮箱会话。/api/me/wallet 返回账面、冻结、可用余额和最近 30 笔充值/消费。

/admin/api/users/:userId/tokens 管理指定账户凭证；/admin/api/users/daily 提供按日统计；/admin/api/ledger 提供最近 200 笔流水；/admin/api/billing 提供收费状态和待核对列表。

## 上线边界

不新增生产依赖；保留单网关 + PostgreSQL + Caddy。数据库第 8 版为新增字段、表和允许多个管理员的约束调整，保留全部历史账目。邮箱真实发送取决于腾讯云 SES 模板获批及配置启用，需要单独核验。媒体用户售价尚未配置，不能在文字收费开启后继续按免费路径调用媒体。
