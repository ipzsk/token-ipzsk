# 分佣边缘场景模拟审查

日期：2026-10-12。范围是本地代码、独立 `gateway_test` 数据库及模拟回执，没有真实扣费、转账或生产迁移。

状态：下表数值为 schema 32 永久规则的测试断言值，规则调整后的集成测试需在隔离库复跑确认。

## 本轮规则

BD 永久取得有效付费 API 消费的 20%，不等上游成本。插件开发者永久取得剩余利润的 40%：有效付费消费减去付费部分应承担的可信实际成本、再减去 BD 佣金，低于 0 时按 0 计；没有 BD 时不扣 BD 项。开发者部分必须等实际成本确认后计算，之后的成本修正只调整开发者。规则没有期限，`enabled` 是唯一运营开关。赠送资金不分佣，退款和拒付按最终净付费消费冲减。

数据库端口必须指向独立的 `gateway_test`。数据库迁移版本为 32，重复迁移需要通过。

## 未决边界

- `historical_sources_review` 保留历史未决账目，须依据原始支付及消费来源人工核账。
- 已领取的 `applying` 是外部调用在途状态；响应不确定转 `review`，由管理员核对。
- 上游成本高于销售收入时，BD 20% 仍按有效付费消费计提，平台承担这部分负毛利；开发者收益为 0。
- 没有真实成本回执的上游（如 DeepSeek 文本）需管理员录入成本，否则开发者收益一直待定。
- schema 31 曾把当时已有的 v1 利润口径请求标成 20%／35%，迁移无法自动区分这批请求，若 schema 31 已在生产运行过需人工核对。
- 本地模拟不能证明生产渠道单位配置、真实支付、真实退款或银行提现已经验收。
