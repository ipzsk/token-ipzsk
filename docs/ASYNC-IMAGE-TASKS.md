# 异步图片任务（2026-09-07）

提交成功即返回平台任务编号。生成耗时与一次 HTTP 请求的超时相互独立，客户端不会再因为任务超过 240 秒而结束查询。

## 后台

- `media-task-sync.mjs` 每 5 秒扫描到期任务，每批最多 20 个，同时查询最多 4 个。
- 按任务年龄采用 5 秒、15 秒、30 秒间隔。GET 查询与后台 worker 共用数据库锁与刷新间隔，多窗口不会重复刷新同一任务。
- 网络异常保留原状态，更新下次查询时间；上游明确结束才保存结束状态。
- 保存任务状态、图片结果及上游确认费用；已结束任务停止状态轮询。余额/账单核对机制沿用已有逻辑。
- 图片通过带权限的原任务下载端点，以流传输，限制 32 MB，不把整张图片积存在服务器内存。
- 无数据库迁移、无新增依赖。

## 客户端

实际桌面插件目录：`~/Library/Application Support/IPZSK Desktop/dsh-home/profiles/desktop/node_modules/@dickpy/dsh-imagegen`。

- 每次异步提交获返回任务编号后，写入 `~/.dsh/dsh-imagegen/pending-tasks.json`，采用原子替换、0600 文件权限。
- 保存任务编号、请求描述与渠道编号，不保存渠道密钥及参考图片像素。
- 重启后查询保存的编号；缺失的批次编号不自动补发，避免未知提交状态导致重复扣费。
- 轮询单次超时 30 秒；网络故障自动恢复，无生图总时长的固定失败阈值。
- 图片加载失败最多自动重试 4 次，之后显示“结果待获取”，点击重新获取只查询原任务。
- 新提交清空旧预览；任务进度显示在结果区域。原来的图片仍保留在历史记录。
- 完成后图片保存到原有历史目录，并清除未完成任务检查点。
